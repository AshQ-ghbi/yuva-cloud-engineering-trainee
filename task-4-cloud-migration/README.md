# Cloud Migration and Cost Optimization Project

## Overview
This module documents the migration of a legacy on-premises e-commerce application to AWS, followed by post-migration cost optimization and performance tuning. 

## Contents
* **`migration-strategy/6-R-framework-analysis.md`**: Evaluation of workload components (Re-host, Re-platform, Refactor).
* **`scripts/dms-task-config.json`**: AWS Database Migration Service (DMS) configuration for zero-downtime database replication.
* **`scripts/s3-datasync-script.sh`**: Script to transfer local NAS file storage to Amazon S3.
* **`reports/tco-comparison.md`**: Total Cost of Ownership (TCO) analysis demonstrating a 38% reduction in infrastructure costs.
